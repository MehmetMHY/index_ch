index_ch: cache, ingest, and smart search

A small add-on for Ch that indexes saved chat history and searches it by meaning. Two flows: how the local cache is built and kept fresh without paying twice, and how a single search query becomes ranked results.

BUILD

build.py

Reads chat JSON from ~/.ch/tmp/, cleans noise, and diffs each file by a SHA-256 content hash.

  • new or changed: insert or re-ingest, clear paid summary and embedding
  • unchanged: skip for free, no rework
  • source file gone: flag archived, kept and searchable forever

PROCESS

process.py

Summarizes, condenses a short blurb, and embeds each chat with OpenAI. The only paid step.

  • resumable: each column skipped when already filled
  • short summary fed from the summary, so it is cheaper to backfill
  • full backfill of ~5600 chats costs about $6 to $7

RETRIEVE

retrieve

Interactive search prompt. Hybrid vector and keyword retrieval fused with RRF, then Groq rerank.

  • query expansion adds one nano call, no extra embedding trips
  • reranker always sees the original query, never a variant
  • each query costs a fraction of a cent
