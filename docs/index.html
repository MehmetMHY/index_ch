index_ch

about

Search your Ch history by meaning! index_ch turns your saved Ch conversations into a local, searchable memory so past answers, decisions, debugging notes, and ideas are recoverable even when you don't remember the exact words.

github · get started · 

$ index_ch
  query: where did I debug the auth redirect

> OAuth redirect loop fix             nov 12   0.96
  Database migration notes            oct 28   0.83
  React state cleanup discussion      oct 03   0.77

why

Your best AI answers are easy to lose. When chats pile up, exact keyword search is not enough. You remember the idea, the bug, or the decision, but not the wording. index_ch retrieves the right conversation anyway.

features

  • semantic search: find conversations by intent and meaning, not just matching words
  • hybrid retrieval: meaning-based search plus keyword matching for better recall
  • concise summaries: each chat becomes a readable preview you can scan quickly
  • local cache: your index and generated metadata are stored on your machine
  • chat browser: browse recent sessions and jump back in when needed
  • terminal native: a CLI with a fuzzy-picking TUI, built for keyboard-driven use

how it works

  1. index: reads saved Ch sessions and strips noisy generated content
  2. process: builds summaries and searchable representations of each conversation
  3. retrieve: search interactively, browse results, open old chats, copy references

use cases

Built for the moments you almost remember.

  • find the chat where you solved a bug
  • recover an implementation plan from last week
  • look up a command or explanation you already asked for
  • browse old sessions by recency
  • collect related chats into a reusable context

privacy

Local-first by design. index_ch is a personal utility for your own machine. It builds a local searchable cache from your saved Ch history instead of turning it into a public web service. Some processing steps may use configured AI services, but the searchable cache and chat index live locally. index_ch is an independent local utility for Ch users.

get started

Give your Ch history a memory. Install it, run index_ch init, and search your first session in under a minute. Your past answers are closer than you think.
